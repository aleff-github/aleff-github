## Featured project

### [NiceTryGPT](https://github.com/aleff-github/NiceTryGPT)

**Less pattern matching. More actual hacking.**

Open-source Agent Skill for reviewing and minimally adapting authorized CTF challenges to reduce cheap LLM shortcuts while preserving the intended vulnerability, learning objective, and human difficulty band.

- Current release: **v0.2.0**
- License: **GPL-3.0-only**
- DOI: **10.5281/zenodo.22858477**
- Website: https://aleff-github.github.io/NiceTryGPT/
- Anthropic Agent Skills submission: https://github.com/anthropics/skills/pull/1798

Cross-agent install:

```bash
npx -y skills add aleff-github/NiceTryGPT --skill nice-try-gpt
```
